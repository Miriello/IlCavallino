# 🍽️ ilCavallino 

Sistema informativo per la gestione dell'area di ristorazione de **Il Cavallino**,
sviluppato come progetto universitario per il corso di Sistemi Informativi.
---
## 📌 Descrizione

Il progetto implementa un'applicazione desktop Java per la gestione dei principali
processi di una tavola calda, integrando gestione del personale, menu, piatti,
ingredienti, allergeni, fornitori, magazzino, vendite e pagamenti.

L'applicazione utilizza un sistema di autenticazione basato sui ruoli: dopo il login,
ogni operatore accede esclusivamente alle funzionalità previste per il proprio ruolo.

L'applicazione è costruita con un'architettura modulare, esiste un gestionale per ogni ruolo
composto da pannelli che racchiudono funzionalità specifiche,
per ogni ruolo saranno presenti i pannelli coerenti con il ruolo aziendale specifico.

## ✨ Funzionalità

### 👨‍💼 Socio
- Gestione del personale e degli account
- Gestione di ingredienti e piatti
- Gestione dei fornitori
- Gestione del menu
- Consultazione delle scorte
- Consultazione delle vendite

### 👨‍🍳 Addetto alla ristorazione
- Consultazione degli ingredienti
- Gestione dei piatti
- Gestione del menu

### 📦 Addetto al magazzino
- Gestione delle scorte
- Controllo delle quantità disponibili
- Individuazione dei prodotti sotto soglia
- Consultazione dei fornitori

### 🧾 Addetto alla vendita
- Consultazione del menu del giorno
- Registrazione delle vendite
- Registrazione dei pagamenti

## 🛠️ Tecnologie

- Java
- Java Swing
- JDBC
- MySQL
